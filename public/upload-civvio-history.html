Upload past store visits

Use the DMQ-Past-Visits-Template.xlsx file. Rows with a Month but no visit date show as "Busy uploading" under Still to visit. Uploading an updated file replaces matching rows.

Step 2 · optional

Past visit photos

Pick one or more photos, then set the store and visit date for each. If the file name has the store code and date (e.g. DMQ-05 2026-08-14.jpg) they fill in automatically. Photos go to Supabase and appear on the visit with the same store and date.
